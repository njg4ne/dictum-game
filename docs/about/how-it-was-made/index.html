How it was made

How the app around the engine was set up: the brief, the tools, and where everything comes from.

The part that makes the game possible, the engine that builds the word lists, is the students' work and has its own page: the students' engine. This page covers the rest.

Contents

  1. Who set it up
  2. What was asked for
  3. What it depends on
  4. How it was checked

Who set it up #

Directed and reviewed by Dr. Nicholas Gardella (njg4ne), who wrote the brief below. The site's code and docs were written with an LLM assistant (Claude Sonnet 5.5, by Anthropic, a large language model), which also ran the profiling, tests and audits; what it did, how that was checked and where a person still mattered is on its own page. The game is a fork of Dictum by Aurorum; the original's artwork has been replaced.

What was asked for #

  • Everything runs in your browser. There is no server to run: the pages are plain files.
  • Any five-letter Latin form is a valid guess, as in the original game. The answer comes from the instructor's word list.
  • The word-list builder is written in Python and runs in the browser, with as little Python as possible.
  • Two views: one for players, and one for instructors, who sign in with GitHub and save word lists to their own GitHub account. Each list comes with a link to give students.
  • Hints for students (grammar notes and the definition) and the answer, all hidden until asked for.
  • Light and dark themes in W&L colors, accessible to everyone, with simple code that a beginner can read.
  • Credit for the students whose work the engine is built from.

What it depends on #

The site serves everything it needs itself, with no outside hosts. The only outside services are GitHub, for sign-in and for saving word lists, and a small helper service that handles GitHub's sign-in code. Credits and licenses for the Latin data, the fonts, the icons and the software are on the attributions page.

How it was checked #

23 tests of the engine (run them yourself), a type check that catches mistakes before the code runs, automatic accessibility checks on every page in both themes, and a click-through of the whole site in a real browser. AUDIT.md in the repository has the details and how to repeat them.

W&L Dictum is a fork of Dictum by Aurorum, for educational purposes only. The W&L name and logo belong to Washington and Lee University.
