The Latin #

Where the words, their meanings and every inflected form come from.

  • Wheelock's Latin(opens in a new tab)

    Frederic M. Wheelock (1956), revised by Richard A. LaFleur since the fifth edition (1995)

    The textbook the course follows, and a book you can buy: the seventh edition (2011) is published by HarperCollins. The game's chapter vocabulary comes from it. This site reproduces none of the book itself, only the list of words by chapter, so students still need the book.

    Wikipedia(opens in a new tab)

  • Wheelock's Latin Vocabulary Tools(opens in a new tab)

    Eric Warmenhoven

    Thank you for sharing this. The chapter-by-chapter vocabulary lists with English meanings that this game's word-list builder reads (static/engine/vocab.csv) come from this site, which Eric Warmenhoven built and published so that Latin students and teachers can use it. It grew out of a replacement for an older Latin vocabulary site, and its source is on GitHub. It is a generous gift to the Latin community, and we are glad to credit and link it.

    Source on GitHub(opens in a new tab)

  • William Whitaker's Words(opens in a new tab) Whitaker's own free-use licence

    William A. Whitaker (1936-2010), a retired US Air Force colonel

    A Latin-English dictionary and parser written in Ada. Its dictionary and endings tables (DICTLINE.GEN, INFLECTS.LAT, UNIQUES.LAT) are the source of every Latin form this game can accept as a guess. Whitaker made the program and data free: "Permission is hereby freely given for any and all use of program and data." His own site is gone; a copy survives at the University of Notre Dame's archives.

    Notre Dame's copy of the original site(opens in a new tab)

  • mk270/whitakers-words(opens in a new tab)

    Martin Keegan

    A cleanup of Whitaker's Ada source that is, in effect, the canonical code today. The data files used here were copied unchanged from this fork.

  • ben-crowell/whitakers-words(opens in a new tab)

    Ben Crowell

    A 2024 fork of Keegan's version, kept building on newer compilers. It differs from the other fork in code and data, and the two were compared when choosing a base for omnes_formae.

  • omnes_formae(opens in a new tab) AGPL-3.0

    njg4ne

    Latin for "all the forms". A Python package built on the Whitaker data (with both forks above as reference) that turns a dictionary word into every one of its tagged forms; the root of the students' engine and of the valid-guess list. It is a derivative of Whitaker's Words and the forks listed above. Its own code and documentation were written with an LLM assistant (Claude); Whitaker's data files in it are unchanged. This site uses the pinned v0.3.0 release, checked against a checksum.

    Documentation(opens in a new tab)

The people and the tools that wrote the game #

Who made what, including the parts where software did much of the typing.

  • Dictum(opens in a new tab)

    Aurorum, at latinvocabularytester.com

    The original Latin Wordle that this is a fork of. All credit for the game idea and its rules belongs to its authors. We have asked for their approval and are waiting for it.

    latinvocabularytester.com(opens in a new tab) · Our request for approval(opens in a new tab)

  • The students' engine

    Five student teams in W&L's Introduction to Computer Science course, CSI 1100 (Fall 2026, section 04). The students' names are on the students' page.

    The Python code that builds word lists. The engine is an amalgam of their submissions, written from scratch around ideas they had first. Students could use their own thinking and, as the course allowed, coding assistants such as GitHub Copilot. We do not know which submissions used which, so we credit the teams for the work and make no claim either way.

  • Dr. Nicholas Gardella (njg4ne)(opens in a new tab)

    Nicholas Gardella, PhD, behind W&L Dictum

    Wrote the brief, directed the work, and reviewed and redirected it throughout.

    Website(opens in a new tab) · ORCID(opens in a new tab) · GitHub(opens in a new tab)

  • Claude(opens in a new tab)

    Anthropic

    A large language model (LLM) that writes code, used through Claude Code, that wrote this site's code, tests and documentation under Dr. Nicholas Gardella (njg4ne)'s direction, and ran the profiling and audits. What it did and how it was checked is on its own page.

  • Design guidance for coding LLMs(opens in a new tab)

    Scott Tolinsky (s-stack), and njg4ne (svg-figures)

    Written guidance on HTML, typography, motion and design review that the assistant read while styling the site. It is kept in .agents/skills/ for reference and is not part of what visitors download. The s-stack repository states no licence.

Open-source software #

The libraries and tools the site is built from and checked with. Everything the pages need is served from this site, with no CDN.

  • Pyodide(opens in a new tab) MPL-2.0

    The Pyodide contributors

    Python compiled to WebAssembly, which runs the engine in your browser.

    Source(opens in a new tab)

  • Svelte and SvelteKit(opens in a new tab) MIT

    The Svelte team

    The framework that builds the pages, which are pre-rendered to plain files.

    SvelteKit(opens in a new tab)

  • Vite(opens in a new tab) MIT

    The Vite team

    The build tool.

  • TypeScript(opens in a new tab) Apache-2.0

    Microsoft

    Types for the site code.

  • Bits UI(opens in a new tab) MIT

    Hunter Johnston and contributors

    The keyboard-navigable menu for word lists, a headless component library.

    Source(opens in a new tab)

  • Octokit(opens in a new tab) MIT

    GitHub and contributors

    Talks to GitHub's API so instructors can save word lists to their own repository.

  • axe-core(opens in a new tab) MPL-2.0

    Deque Systems

    The accessibility checker run on every page in both themes.

  • Playwright(opens in a new tab) Apache-2.0

    Microsoft

    Drives a real browser for the accessibility and end-to-end tests.

  • Lighthouse(opens in a new tab) Apache-2.0

    Google Chrome team

    A second accessibility and performance audit, run from the command line.

  • Python(opens in a new tab) PSF License

    The Python Software Foundation

    The language of the engine and its tests.

Services #

The only outside services the site talks to, and only on the instructor page and for shared word lists.

  • GitHub(opens in a new tab)

    GitHub, Inc.

    Sign-in, the instructor's data repository, and the raw files students load word lists from.

  • Secret Keeper (ghsk)(opens in a new tab)

    njg4ne, a fork for Cloudflare Workers of Henrik Joreteg's github-secret-keeper

    A small service that trades GitHub's one-time sign-in code for a token, so this site never holds a secret. Neither repository states a licence.

    The original, github-secret-keeper(opens in a new tab)
